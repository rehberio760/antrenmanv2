ANTRENMAN ÇİZELGEM - APK YAPMA

YOL A - Bilgisayarında (Android Studio ile)
1) Node.js (LTS) ve Android Studio kur.
2) Bu klasörde terminal aç:
   npm install @capacitor/core @capacitor/android
   npm install -D @capacitor/cli
   npx cap add android
   npx cap sync android
   npx cap open android
3) Android Studio: Build > Build Bundle(s) / APK(s) > Build APK(s)
   APK: android/app/build/outputs/apk/debug/app-debug.apk

YOL B - Hiçbir şey kurmadan (GitHub ile)
1) github.com'da ücretsiz hesap aç, yeni bir depo (repository) oluştur.
2) Bu klasörün İÇİNDEKİ her şeyi (.github klasörü dahil) depoya yükle.
3) Depoda Actions sekmesi > "APK olustur" > Run workflow.
4) Birkaç dakika sonra bitince, çalışmanın sayfasının altındaki
   "antrenman-cizelgem-apk" dosyasını indir, zip'ten APK'yı çıkar.

Uygulamanın kodu www/index.html dosyasındadır.
